# Talkative AI Frontend

A React + Vite + Tailwind-ready-style frontend for the first Talkative AI screen.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The first screen includes:
- Talkative AI branding
- Mood selection
- Six conversation modes
- Responsive mobile layout
- Selected mood state
- Explore all moods
- Start button with a mock action

The AI/backend is intentionally mocked for this first frontend stage and can be connected to a Python FastAPI backend later.
